# Button

按钮触发一个动作，文字以动词开头并说明结果。

## 何时使用
- **主按钮**（`cm-btn--primary`，`brand-500` 填充、`on-brand` 文字）：每个区域最多一个，例如顶栏的"运行"、对话框的确认。
- **次按钮**（默认）：并列的其他操作，如"试运行""保存"。
- **幽灵按钮**（`cm-btn--ghost`）：工具栏、面板标题栏里的低频操作。
- **危险按钮**（`cm-btn--danger`，`status-failed` 填充、`on-danger` 文字）：不可撤销的操作，文字写明后果（"终止运行""删除能力"）。

## 尺寸
`--sm` 26px（卡片内、表格内），默认 32px（工具栏、面板），`--lg` 40px（对话框、空状态、宣发行动区）。只放图标用 `--icon`，必须带 `title` 与 `aria-label`。

## 规则
- 图标在文字左侧，间距 `space-2`，16px Lucide 图标。
- 禁用态保留可见，并用 tooltip 说明原因（如"你没有运行权限，请联系流程负责人"）。
- 不要写"确定""提交""OK"；对话框的"取消"除外。
