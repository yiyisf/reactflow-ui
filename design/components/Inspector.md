# Inspector

选中节点或步骤后，右侧显示的配置面板。

## 结构
1. 头部：分类图标块、名称、`taskReferenceName · TYPE`、更多菜单。
2. 标签页：参数 / 输出 / 重试与超时（开发者模式另有 JSON）。
3. 分区：标题 12px 600 `text-muted`，分区之间 `border-subtle` 分隔，分区内字段间距 `space-4`。
4. 底部：能力引用与版本锁定信息。

## 规则
- 宽 320px，`surface-1`，停靠右侧时只用左边框，不加阴影；200ms 滑入。
- 能根据上下文推断的字段标注"自动带出"并预填；用户可改。
- 修改即时生效并进入撤销栈，不需要"保存"按钮；校验错误同步出现在诊断面板。
