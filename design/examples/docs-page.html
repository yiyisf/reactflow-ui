自助接入

读完这一页，你可以让新团队在测试环境里独立登记产品、生成规范的流程名，并跑通第一个流程。

前提宿主需要实现 onboarding provider；没有配置时，IDE 不显示"新建流程向导"和"申请上线"入口，行为与 1.2.0 一致。

1. 安装

npmpnpmyarn
$npm install @yiyi_zhang/reactflow-ui@1.3.0 reactflow react react-dom

2. 在外层注册 providers

provider 实例只创建一次，页面里所有 IDE 实例共用。

WorkflowStudio.tsx
import { WorkflowIDE, WorkflowIdeProvider } from '@yiyi_zhang/reactflow-ui';

const providers = {
  onboarding: createOnboardingProvider(governanceApi), // 1.3.0 新增
};

<WorkflowIdeProvider providers={providers}>
  <WorkflowIDE uiMode="business" />
</WorkflowIdeProvider>

3. 实现 onboarding 契约

方法治理服务接口说明
listDomains *GET /api/library/domains业务域列表
startTrial *POST /api/onboarding/trial登记产品并开通试用；冲突时返回 conflict
requestPromotionPOST /api/onboarding/promote提交上线申请，返回 requestId
getPromotionGET /api/onboarding/promote/{id}审批进度 SUBMITTED → APPROVED
注意生产环境不出现"开始试用"；类型段只可选 custom 或 std。

4. 验证

1
在 TEST 环境打开工作台顶栏出现"开始试用"引导卡片
2
新建流程，走完三步向导流程名形如 tmp-业务-云资源-order-create
3
沙箱试跑后申请上线控制台打印 promotion_requested 事件
