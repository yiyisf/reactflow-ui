# v1.3.1 发布计划：补齐与打磨

> 状态：规划中 · 在 v1.4.0（放心上线）之前插入的修复版本 · 演进路线见 `docs/roadmap.md`

## 目标

不加新能力，把已经发布的功能做"对"、做"好用"：

1. **沙箱真实执行**：不依赖外部系统的任务（INLINE、JSON_JQ_TRANSFORM、SWITCH / DECISION、DO_WHILE、FORK_JOIN(_DYNAMIC)、JOIN、SET_VARIABLE、TERMINATE、WAIT）在浏览器里按 Conductor 语义真实执行；只有需要外部系统的任务（HTTP、SIMPLE、HUMAN、EVENT、KAFKA_PUBLISH、SUB_WORKFLOW 等）才用模拟数据，并在界面上标明。
2. **产出的流程能被 Conductor 接受**：新建、编辑、导入的每种任务类型都生成合法的 Conductor JSON，往返不丢字段。
3. **界面不说谎**：没有点了没反应的按钮、没有编造的数据、状态都是"颜色 + 图标 + 中文"。

## 排查方式

2026-10-25 按五个功能区逐条读代码核对（往返、解析类结论用 node 实际跑过最小用例）。共约 110 条：P0（结果错误 / 数据丢失 / 崩溃 / 安全）38 条，P1（功能不完整或误导）48 条，P2（体验打磨）约 25 条。下表只列 P0 与 P1；编号在 PR 与提交里引用。

## 一、沙箱执行引擎（`src/utils/localSandboxEngine.ts`）

| 编号 | 级别 | 现状 | 修复 |
|---|---|---|---|
| S1 | P0 | INLINE 不执行脚本，返回 `{evaluated:true, ...入参}` 的假结果 | 按 `inputParameters.evaluatorType`（javascript / graaljs）真实执行 `expression`，`$` 绑定入参；脚本在隔离的 Web Worker 中运行，带超时，关掉网络与存储接口 |
| S2 | P0 | JSON_JQ_TRANSFORM 只支持 `.a.b` 取值，其它表达式返回 `{transformed:true}` 假结果 | 内置 jq 子集解释器（路径、`.[]`、管道、逗号、对象/数组构造、算术比较、`select/map/length/keys/has/add/join/to_entries/from_entries/sort_by/group_by/unique/first/last/tostring/tonumber/ascii_downcase/split/test`、`if-then-else`、`//`、字符串插值、`as $x`）；遇到不支持的语法**判为失败并说明**，不再伪造成功 |
| S3 | P0 | SWITCH：javascript 求值器不执行，表达式字符串被当作值做子串匹配；找不到分支时走**第一个分支**而不是 `defaultCase` | value-param 读 `inputParameters[expression]`；javascript/graaljs 真实执行；未命中走 `defaultCase`，与 Conductor 一致 |
| S4 | P0 | DECISION 的 `caseExpression` 不执行 | 同 S3 |
| S5 | P0 | DO_WHILE 忽略 `loopCondition`，固定跑 `maxLoopIterations`（默认 2）轮 | 每轮后按 Conductor 语义执行条件（`$.<loopRef>.iteration`、子任务输出、入参）；`maxLoopIterations` 改为安全上限，触顶时标"已达沙箱上限"而不是成功 |
| S6 | P0 | FORK_JOIN_DYNAMIC、DYNAMIC 落入默认分支，返回通用假输出 | 读取 `dynamicForkTasksParam` / `dynamicTasksInput` 生成并执行动态任务再 JOIN；DYNAMIC 按 `dynamicTaskNameParam` 解析 |
| S7 | P1 | 表达式只支持 `a.b.c`，不支持 `items[0].id`、`${ref.input.x}`；解析不到的 `${...}` 原样留下且无提示 | 支持数组下标与 `.input`；未解析的引用记入该任务的警告 |
| S8 | P1 | 结果里看不出哪些任务真实执行、哪些是模拟 | 每个任务标 `sandbox: executed / mocked`；运行视图显示徽标 |
| S9 | P1 | 默认入参凭空带上 `orderId / amount: 299 / currency` 等与流程无关的字段 | 只生成流程声明与表达式里实际引用的入参 |

**接口变化**：脚本执行必须异步（Worker），新增 `executeLocalSandboxDryRunAsync()`，界面上所有入口改用它。现有同步 `executeLocalSandboxDryRun()` 保留且行为兼容：同步接口不执行脚本，INLINE 与 javascript 条件标为"同步接口未执行"，不再给出假结果。

## 已知限制（1.3.1 不做）

- HTTP、SIMPLE、HUMAN、EVENT、KAFKA_PUBLISH、SUB_WORKFLOW 等依赖外部系统的任务在沙箱里仍用模拟数据（可在配置台自定义输出与故障）。
- jq 只支持常用子集；不支持的语法会明确判为失败。
- 沙箱的 JavaScript 运行在浏览器 Worker 中，语义按 ECMAScript，与 GraalJS 的少数差异（如 Java 互操作）不模拟。
