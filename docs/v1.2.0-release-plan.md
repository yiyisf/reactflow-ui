# v1.2.0 发布计划：流程库就绪

> 目标发布：2026-10-30 · 演进路线见 `docs/roadmap.md`

## 目标

让内部项目可以**基于真实治理服务**使用流程库：在业务模式里按业务域选到库能力、引用时固定版本、升级前看差异；AI IDE 能检索并正确引用库能力。同时让 Demo 完整展示这些能力，作为灯塔团队陪跑（11 月）前的演示与接入基线。

| # | 内容 | 验收 |

### 不在本版本

自助接入向导、接口导入、埋点（v1.3.0）；发布审核流、影子运行（v1.4.0）；Schema 助手、组织模板源（v1.5.0）。

## 人工走查清单

**业务模式（#44、#45）**
- [ ] 卡片视图中输入时焦点不丢失，展开项不收起
- [ ] 卡片视图编辑后切回画布，图形正确刷新
- [ ] 撤销 / 重做正常，长时间编辑后无明显卡顿
- [ ] 三层嵌套（分支内的并行内的循环）可增删改，编译结果正确

**流程库（#46、#47，需 Demo 演示后端）**
- [ ] 动作选择器按业务域分组，"其他"在最后；搜索跨全部动作
- [ ] 设置 `currentWorkflowLevel = L1` 时看不到 L2 / L3 能力
- [ ] 引用库能力后步骤显示固定版本；库有新版本时出现"有新版本"，升级差异正确列出受影响的已填值
- [ ] 固定版本被撤回或能力下线时显示"版本不可用"，编译结果不变
- [ ] 目录加载失败时显示重试，不影响编辑
- [ ] AI IDE 能检索到库能力（含按业务域），生成的子工作流带固定版本
