# 宣传页与宣发

版本宣传页、海报、视频、社媒卡片都按 Bento Launchpad 组织：极光夜空做底，一句大标题，一排数字，一组便当卡片，一个明确的行动。

## 版本宣传页结构

沿用 v1.3.0 宣传页已经验证过的叙事顺序，统一换成 CMASTER 视觉：

1. **顶栏**（`surface-0` 半透明 + 模糊，64px）：标志 + 产品名、版本胶囊（`radius-pill`，`brand-tint` 底、`brand-text` 字，"v1.3.0 最新发布"）、锚点导航、右侧主按钮"进入工作台"。
2. **Hero**（极光背景）：版本胶囊 → `display-xl` 标题（第二行关键词用渐变）→ `prose` 导语（`text-secondary`，最宽 680px）→ 特性胶囊一行 → 安装命令终端（Terminal）→ 主按钮 + 两个次按钮 → 一行 `caption` 发布说明。
3. **数字条**：4 张 StatTile（`metric` 数字 + `title-sm` 单位 + `caption` 说明），讲清这个版本"几步、几种、几个"。
4. **主题区块 × N**：每块 = SectionHeader（eyebrow + `display` 标题 + 导语）+ Bento 网格或交互演示。每块只讲一个主题。
5. **接下来**：路线图三张卡（版本号用 `code` + `brand-text`）。
6. **亲手试试**：步骤轨道（编号圆点）+ 右侧资源卡片列表。
7. **页脚**：历史版本、在线演练场、GitHub、npm，文字链接，不用 emoji。

## 主题色轮换

版本宣传页和海报一样使用活动主题色，每个版本换一个，避免审美疲劳。

- 在 `<html>` 上写 `data-mode="dark" data-campaign="<主题>"`，并引入 `/src/styles/cmaster-tokens.css` 与 `/src/marketing/campaign.css`。页面里的强调色一律用 `--a`（主题色）、`--a-hi`（渐变与悬停）、`--on`（主题色实底上的文字），其余颜色用 `--cm-*` tokens。
- 先按版本主题从对照表里选（Ember 发布与总览、Glacier 数据与集成、Nebula AI、Signal 里程碑与数字、Solar 活动与培训）；几个都合适时可以随机选，但**不能与上一个版本相同**。
- 标志始终是品牌橙；非 Ember 主题时，标志是页面里唯一的橙色。成功 / 失败 / 警告等状态色保持语义，不跟主题色走。
- `src/styles/releasePages.test.ts` 会检查：每页一个主题色、相邻版本不重复、没有 emoji、颜色只来自 tokens（标志除外）。

| 版本 | 页面 | 主题色 |
|---|---|---|
| v1.0.0 | `v1-0.html` | Ember |
| v1.1.0 | `v1-1.html` | Nebula |
| v1.2.0 | `v1-2.html` | Signal |
| v1.3.0 | `v1-3.html` | Glacier |
| v1.3.1 + v1.3.2 | `index.html` | Ember |

发新版本时：把当前 `index.html` 另存为 `v1-<n>.html` 归档，新首页选一个与上一版不同的主题色，并在上表加一行。

## Bento 网格

- 12 列网格，间距 `space-4`。常用组合：8 + 4（主卡 + 侧卡）、4 + 4 + 4（三张特性卡）、3 × 4（数字条）、12（全宽演示）。
- 卡片内顺序：标签（eyebrow 或带图标的小胶囊）→ `title-lg` 标题 → `body` 描述 → 内容（表格、代码、列表、截图）。
- 一屏内最多一张卡使用强调描边（`brand-500` 1px + `glow-select`），代表本节最重要的点。
- 移动端全部单列，间距 `space-3`。

## 海报与视频

单页海报、社媒图片与活动主题色的完整规则见"海报与社媒"一节；这里只列视频与宣传页共用的要点。

- **地色与光：** `canvas` + 三色极光；可以叠一层 `canvas-grid` 点阵（透明度 ≤ 40%）。
- **标题：** `display-xl`，关键词渐变；每帧只讲一件事。
- **截图：** 真实 IDE 截图放进 `radius-xl` 窗口，`shadow-dialog`，1px `border-default` 描边，上方可加一条 `aurora-brand` 光边。不套设备外壳。
- **数字：** 用可核实的事实（如"1000+ 条流程在平台运行"），`metric` 样式。
- **行动区：** 标志 + 字标 → 口号 → 适用人群胶囊 → 承诺 → 联系方式（`brand-500` 按钮样式 + `glow-brand`）。当前口号"拖一拖，流程就跑起来"，承诺"首个流程，我们陪你跑通"。
- **视频：** 镜头转场 300–600ms 淡入上移；不再使用扫描线、故障闪烁、HUD 角框等科幻元素，技术感由界面本身与代码胶囊提供。

## 常用尺寸

| 用途 | 尺寸 | 版式 |
|---|---|---|
| 版本宣传页 | 内容宽 1120px | 见上方结构 |
| 竖版海报 / 内网 Banner | 1080 × 1920 | 上 1/3 标题，中部截图卡，底部行动区；四周 `space-24` |
| 横版视频 | 1920 × 1080 | 左上 eyebrow + 标题，右侧或中部演示界面；字幕在底部 120px 内 |
| 社媒方图 | 1080 × 1080 | 极光 + 标题居左 + 截图卡右下出血 |
| 群聊卡片封面 | 1200 × 630 | 标志 + 一句标题 + 版本胶囊，不放截图 |

## 不要

- 不要用 emoji、霓虹多色、粒子网络、透视网格地面。
- 不要用 AI 生成的人物或场景插画。
- 不要展示尚未上线的能力；路线图卡片要标明"规划中"和目标时间。
