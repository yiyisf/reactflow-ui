# 海报与社媒

单页海报、朋友圈 / 公众号配图、群聊卡片、内网 Banner 都遵循这一节。它们和宣传页同属 Bento Launchpad，但离开了网页，只剩一张图来让人记住 CMASTER，所以版式更大、更少、更有节奏。

## 不变的东西

无论哪张图、哪个主题色，下面这些都不变，它们就是"一眼认出是 CMASTER"的依据：

1. **标志永远是 CMASTER 橙**（`brand-500`），节点内填充随地色。不随主题色变色，不描边、不加光。
2. **品牌条在左上角**：标志 + 字标 CMASTER（`sans` 800，首字母 C 橙色）+ 一个系列胶囊（如 `v1.3.0`、`LABS`、`开放日`）。位置固定在安全边距内，所有尺寸都一样。
3. **深海军蓝夜空**：地色 `canvas`（暗）或纸面模式的 `canvas`（亮），不用纯黑、不用彩色满底。
4. **字体**：Geist + 苹方，标题 800；英文小标题与编号用 `mono`。
5. **结构**：一句主标题、一个视觉主体、一个行动，三者缺一不可，多一样都嫌挤。

## 活动主题色

为了让不同主题的内容一眼可分，海报和社媒图可以换"活动主题色"（`campaign-*`）。主题色替换的是**强调色**：标题关键词渐变、eyebrow、主题光晕、轨道图形、行动按钮。标志不换。

| 主题 | 强调 | 高光 | 按钮文字 | 用于 |
|---|---|---|---|---|
| Ember 余烬 | `campaign-ember` | `campaign-ember-hi` | `on-campaign-ember` | 默认。版本发布、产品总览、招募试用 |
| Glacier 冰川 | `campaign-glacier` | `campaign-glacier-hi` | `on-campaign-glacier` | 数据、接口导入、集成与扩展点 |
| Nebula 星云 | `campaign-nebula` | `campaign-nebula-hi` | `on-campaign-nebula` | AI 编排、Labs 前沿探索 |
| Signal 信号 | `campaign-signal` | `campaign-signal-hi` | `on-campaign-signal` | 里程碑、数字战报、成功案例 |
| Solar 日冕 | `campaign-solar` | `campaign-solar-hi` | `on-campaign-solar` | 活动、培训、开放日、直播 |

- **一张图只用一个主题色。** 另外两束极光可保留 `aurora-data` / `aurora-ai` 作为环境光，但强度降到一半。
- **非 Ember 主题时，标志是画面里唯一的橙色。** 不要再出现橙色按钮或橙色文字，避免两种强调色打架。
- **同一系列用同一主题色。** 例如"AI 编排 5 讲"全部用 Nebula，编号 `01 / 05` 区分篇目。
- **纸面模式**（浅底）：用于打印、群聊卡片、白底文档插图。地色 `canvas`（亮），强调色用该主题的"强调"值，标题渐变改为纯色。

## 标志性图形：轨道（Orbit）

从标志里的 C 形圆弧和三个节点衍生出的超大图形，是海报的品牌纹样：

- 一段大圆弧（半径约为画面宽度的 0.6–0.9），**从画面右侧或底部出血**，只露出 1/3 到 1/2。
- 弧上 2–4 个节点圆点，其中一个实心（主题强调色），其余空心；节点之间可用细直线连向画面里的内容（例如连到截图卡或数字）。
- 线宽 2–3px，主题强调色 30–50% 不透明度；节点直径 16–28px。
- 每张图只放一组轨道；与标题保持至少 `space-12` 的距离，不压字。

另有两个可选辅助纹样：`canvas-grid` 点阵（20px 间距，≤ 40% 不透明度）、细网格框（1px `border-default` 的 Bento 卡边）。不再使用粒子网络、扫描线、透视地面。

## 版式

以 1080px 宽为基准，所有尺寸按比例缩放。

- **安全边距**：四周 `space-24`（96px）；社媒方图 72px；群聊卡片 64px。
- **网格**：12 列，栏间距 24px；基线 8px。
- **分区（竖版 1080×1920）**：品牌条（顶部 96px 起）→ 标题区（约占 1/3）→ 视觉主体（截图卡 / 大数字 / 流程图，约占 2/5）→ 证据（3 个数字或 3 个胶囊）→ 行动区（底部 96px 内结束）。
- **分区（方图 1080×1080）**：品牌条 → 标题 → 视觉主体右下出血；行动区可省略，改为一行 `poster-caption` 链接说明。
- **分区（横卡 1200×630）**：左 7 列放品牌条 + 标题 + 一行说明，右 5 列放轨道图形或一个数字；不放截图。
- **对齐**：标题与正文左对齐；只有纯数字战报可以居中。

## 字体（海报专用，基于 1080px 宽）

| 样式 | 规格 | 用途 |
|---|---|---|
| `poster-hero` | 112 / 116，800，-0.03em | 主标题，最多 3 行，每行不超过 8 个汉字 |
| `poster-headline` | 64 / 76，700 | 方图标题、竖版次级标题 |
| `poster-lead` | 32 / 48，500 | 一句话说明，`text-secondary` |
| `poster-metric` | 168 / 168，800，-0.04em | 战报大数字，单位用 `poster-lead` |
| `poster-eyebrow` | 22 / 28，`mono` 500，0.18em | 英文小标题、系列编号，主题强调色 |
| `poster-caption` | 22 / 32，400 | 脚注、日期、链接说明 |

## 视觉主体

按内容选一种，不要叠加：

- **产品截图卡**：真实 IDE 截图，`radius-xl`，1px `border-default`，`shadow-dialog`，顶部 1px 主题色光边；可以出血、可以轻微倾斜（≤ 6°），不套设备外壳。
- **大数字**：`poster-metric`，下方一句说明；最多 3 组，等分排列。
- **流程链**：3–5 个节点卡片（与 IDE 节点同款）用主题色连线串起来，展示一个真实流程。
- **代码胶囊组**：3–6 个 `code` 胶囊错落排列，适合 SDK / 集成主题。

## 行动区

- 固定顺序：一句口号或承诺 → 行动块（主题色填充、对应 `on-campaign-*` 文字、`radius-md`，写"联系人 zhang"或"扫码进入工作台"）→ 二维码位（白底 `radius-lg`，边长 ≥ 160px，周围留白 ≥ 16px）。
- 日期、地点、链接用 `poster-caption`，`text-muted`。

## 社媒系列

- 系列内所有图：品牌条位置、主题色、轨道方向一致；eyebrow 写系列名 + 编号，如 `AI 编排 · 02 / 05`。
- 封面图标题最大、信息最少；内页图可以有 3 条要点。
- 公众号首图 900×383 只放字标 + 一句标题 + 轨道，不放截图。

## 不要

- 不要改标志颜色，也不要在非 Ember 主题里再用橙色做第二强调。
- 不要在一张图里混用两个主题色。
- 不要用 emoji、AI 生成的人物或场景插画、库存照片。
- 不要放没上线的功能或无法核实的数字。
- 不要把小于 22px 的文字放进海报（在 1080 宽基准下）。
