# LibraryItem

能力库中的一个可复用能力，可拖入画布或业务卡片流。

## 使用者提供
- 名称（`title-sm` 13px）、业务域（来自命名规范中的业务域）、可选的引用次数。
- 类型标签：`std`（标准能力，`brand-text` 描边）、`custom`、`tmp`。
- 版本状态：有新版本时用 `status-warning` 文字提示；已引用的步骤保持锁定版本，不自动升级。

## 规则
- 面板宽 264px，`surface-1`；搜索框置顶，`surface-3`。
- 悬停 `surface-3`，拖拽中或选中 `brand-tint` + `brand-500` 边框。
- 左侧 8px 分类色块与节点的 `cat-*` 一致，让用户在库和画布间对上号。
- 无权限查看的能力不出现在列表中；有查看权限但无引用权限时，显示锁图标并禁用拖拽。
