# ShadowDiff

AI 生成或修改流程时的 Shadow Graph 预览。任何 AI 改动都必须先以提案呈现，用户采纳后才写入流程。

## 规则
- 新增：`diff-added` 实线边框 + "新增"标签。修改：`diff-modified` 边框 + 标签，meta 行写明"旧值 → 新值"。移除：`diff-removed` 虚线边框、55% 透明度 + "移除"标签。
- 标签文字用 `canvas` 色，位于节点右上角。颜色之外必须有文字标签。
- 评审条浮在画布顶部居中：变更摘要（等宽字体）+ 放弃 / 逐个查看 / 全部采纳。"全部采纳"是唯一主按钮。
- 采纳后进入一个撤销步骤，可一次撤回整个提案。
