# IDE 布局与交互

适用于 `WorkflowIDE` 与 `AiWorkflowIDE`。目标：第一次打开的一线同事知道从哪开始，熟练的研发不被打断。

## 区域划分

```
┌──────────────────────────── 顶栏 48px ─────────────────────────────┐
│ 标志 · 流程名 · 保存状态        模式切换        撤销 重做 · 诊断 · 试运行 · 运行 │
├──────────┬───────────────────────────────────────────┬─────────────┤
│ 能力库    │                                           │ 属性面板     │
│ 264px    │                 画布                       │ 320px       │
│ 可收起    │        浮动工具：缩放 · 血缘 · ⌘K          │ 选中时出现   │
├──────────┴───────────────────────────────────────────┴─────────────┤
│ 底部 Dock：收起 36px / 展开 280px（JSON · 运行日志 · 瀑布流 · 诊断）    │
└────────────────────────────────────────────────────────────────────┘
```

- **顶栏**（`surface-0`，高 `space-12`）：左侧身份（标志、流程名、"已保存 · 2 分钟前"），中间模式切换，右侧操作。主操作"运行"只有一个，用主按钮；"试运行"用次按钮。
- **能力库**（`surface-1`，宽 264px）：搜索框置顶，业务域筛选，能力条目可拖入画布。收起后保留 48px 图标栏。
- **画布**（`canvas`）：点阵 `canvas-grid`，间距 `space-5`。缩放与小地图放左下，血缘开关与 ⌘K 放画布顶部居中的浮动条（`shadow-float`）。
- **属性面板**（`surface-1`，宽 320px）：选中节点时从右侧滑出（200ms），未选中时显示流程级设置。分区标题用 `caption` 600，分区间距 `space-6`。
- **底部 Dock**：标签切换 JSON、运行日志、瀑布流、诊断。诊断有错误时，标签上显示 `status-failed` 计数徽章。

现有的右上角"毛玻璃胶囊工具栏"（ActionBar）拆分为两处：编辑类操作（撤销、重做、诊断、配置）和运行类操作（试运行、运行）进入顶栏；画布视图类操作（血缘、⌘K、缩放）留在画布浮动条。

## 三档模式

| 模式 | 面向 | 画布形态 | 显示 | 隐藏 |
|---|---|---|---|---|
| 业务 | 一线同事 | 纵向步骤卡片流（StepFlow） | 步骤名、关键参数摘要、运行故事线 | 引用名、类型、JSON |
| 标准 | 日常编排 | DAG，节点 240px | 标题、类型、引用名、耗时 | 原始 JSON（Dock 中可开） |
| 开发者 | 研发 | DAG + 分屏 JSON | 全部字段、W-LSP 补全、血缘 | 无 |

- 模式切换使用 ModeSwitch 组件；切换时保持选中对象和视口中心不变。
- 业务模式下无法用卡片表达的结构（`isProFallback`）显示为"高级步骤"卡片，并提供"在开发者模式中编辑"的链接。

## 语义缩放（LOD）

沿用现有阈值：

- **鸟瞰**（缩放 < 0.55）：节点只显示分类色块和标题，标题用 `title-md` 以保证缩小后可读。
- **标准**（0.55 – 1.15）：标题、类型 `code-sm`、引用名、耗时。
- **微距**（> 1.15）：在节点内展开关键入参摘要（如 `GET https://…`、SWITCH 表达式）。

## 核心交互

- **添加步骤：** 从能力库拖入；或悬停连线出现 + 按钮插入；或在空白处双击打开 NodeSelector。拖动时目标位置显示 `brand-tint` 落点。
- **引用上游数据：** 在参数框输入 `${` 或点击"引用"按钮，弹出 W-LSP 补全；选中后插入为 DataPill（`data` 冰蓝胶囊），而不是裸文本。
- **AI 微调（⌘K）：** 选中节点按 ⌘K，指令栏在节点上方出现（CommandBar）。AI 结果以 Shadow Graph 呈现，顶部出现评审条：全部采纳 / 逐个采纳 / 放弃。
- **试运行与运行：** 试运行在浏览器沙箱执行，画布顶部出现 `data-tint` 横条"试运行中 · 不会调用真实系统"；真实运行前弹确认对话框，写清会调用哪些系统。
- **运行态：** 节点边框与徽章按状态着色；Dock 自动切到运行日志；业务模式显示 RunTimeline。失败节点提供"诊断建议"卡片（原因 + 可执行的修复操作）。
- **权限：** 无权限的操作保持可见但禁用（`text-disabled`），tooltip 说明原因和联系人；不要直接隐藏，避免用户以为功能不存在。

## 空状态

- 空画布：居中显示标志、`title-lg` "从一个步骤开始"、两个入口按钮"从能力库选择""用 AI 描述需求（⌘K）"，下方列 3 个常用模板。
- 搜索无结果：说明没找到什么，并给出替代动作（"换个关键词，或 在能力库申请新能力"）。

## 反馈

- 保存、发布、复制等轻量结果用 Toast（右下角，3 秒）。
- 需要用户决定的事用 Dialog；不可撤销的操作（终止运行、删除能力）主按钮用 `status-failed` 填充，按钮文字写明后果（"终止运行"而非"确定"）。
- 加载超过 300ms 才显示加载指示，避免闪烁。
