API IMPORT

已有接口，几步变成流程步骤

粘贴或上传，自动识别格式，勾选接口后插入。每个接口生成一个 Conductor HTTP 任务。

四种来源

粘贴就能认出格式

curl → HTTP 任务
# 粘贴的 curl
curl -X POST 'https://itsm.example.com/api/tickets' \
  -H 'Authorization: Bearer ••••••' -d '{"title":"磁盘告警"}'

// 编译结果
{ "type": "HTTP", "uri": "https://itsm.example.com/api/tickets",
  "headers": { "Authorization": "${workflow.input.authorization}" } }
敏感头不落定义

凭据永远不写进流程

  • Authorization Cookie 自动换成 ${workflow.input.xxx}
  • 出参取 2xx 响应 schema，可直接被下游引用
  • YAML 格式请先转为 JSON（不引入 YAML 依赖）
EXTENSION POINTS

配置一次，处处生效

在外层配置 providers，页面里所有 IDE 实例共用；没配的能力不显示入口。

WorkflowStudio.tsx
import { WorkflowIDE, WorkflowIdeProvider } from '@yiyi_zhang/reactflow-ui';

const providers = {
  library: libraryProvider,       // 1.2.0 已有：流程库
  onboarding: onboardingProvider, // 1.3.0 新增：新建流程向导 + 申请上线
  telemetry: telemetrySink,       // 1.3.0 新增：接入埋点
};

export function WorkflowStudio() {
  return <WorkflowIdeProvider providers={providers}>
    <WorkflowIDE uiMode="business" />
  </WorkflowIdeProvider>;
}
解析顺序

逐字段，就近优先

1组件专用 prop
2组件 providers prop
3外层 WorkflowIdeProvider
4都没有：不显示该入口
