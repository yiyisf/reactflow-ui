# Toolbar

顶栏承载流程身份、模式切换和全局操作，替代现有的右上角胶囊工具栏（ActionBar）中编辑与运行相关的部分。

## 结构
1. 标志 + 流程名 + 保存状态（`caption`，`text-muted`）。
2. 居中的 ModeSwitch。
3. 编辑组：撤销、重做（只放图标）| 诊断（有错误时带 `status-failed` 计数）、配置。
4. 运行组：试运行（次按钮）、运行（主按钮）。

## 规则
- 高 48px（`space-12`），`surface-0` 背景，底部 `border-default`。
- 组之间用 20px 高的竖线分隔，组内间距 `space-1`。
- 运行态时，运行组替换为 继续 / 暂停 / 终止 / 重试，"终止"用危险按钮。
- 画布视图类操作（数据血缘、⌘K、缩放）不进顶栏，放在画布浮动条。
- 不使用 emoji，一律 Lucide 图标；映射见 README 的"图标"一节。
