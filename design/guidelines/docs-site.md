# 文档站

文档站和宣传页是同一套视觉：首页沿用极光与 Bento，正文页去掉极光，回到安静、好读的阅读界面。默认深色，右上角可切换浅色。

## 技术选型建议

- **首选 Fumadocs**（Next.js + MDX）：React 组件可以直接嵌进文档做实时演示（直接渲染 `WorkflowIDE`），与现有 Vercel 部署方式一致，自带 ⌘K 搜索和深浅主题。
- 备选 Starlight（Astro）：静态输出更轻，React 演示以 island 方式嵌入。
- 无论选哪个，主题层只做一件事：把本系统的 tokens 映射到框架的 CSS 变量，组件样式按下方规范覆盖。

## 布局

```
┌──────────────── 顶部导航 64px（surface-0，底部 border-default）────────────────┐
│ 标志 CMASTER Docs · 版本切换胶囊      搜索 ⌘K      GitHub · 主题切换 · 进入工作台 │
├────────────┬──────────────────────────────────────────────┬────────────────┤
│ 侧边栏 264px │ 正文 最宽 760px                                │ 本页目录 220px   │
│ surface-1   │ 面包屑 → eyebrow → H1 → 导语 → 正文            │ 当前项 brand-text │
│ 分组标题     │                                              │ 左侧 2px 指示线   │
└────────────┴──────────────────────────────────────────────┴────────────────┘
```

- 1280px 以下隐藏右侧目录；960px 以下侧边栏收进抽屉。
- 侧边栏：分组标题用 `eyebrow`（`text-muted`），条目 `body-sm`；当前页 `brand-tint` 底 + `brand-text` 字 + 左侧 2px `brand-500` 竖线；新增内容加 `caption` 小胶囊"新"。
- 正文：H1 `display`（文档首页）或 `title-lg` 加大到 32px（普通页），H2 `title-lg`，H3 `title-md`，正文 `prose`；段落间距 `space-4`，H2 上方 `space-12`。

## 文档首页

- 极光背景 + 居中 `display` 标题"用 CMASTER 编排你的流程" + 搜索框（大号，⌘K）。
- 下方 Bento 入口：快速上手（8 列主卡，带 Terminal）+ 业务模式 / 开发者 / AI / 集成参考（各 4 列）。
- 底部"最新版本"条：版本胶囊 + 一句话 + 链接到宣传页。

## 正文组件

- **Callout**：提示 `success-tint` + Lightbulb，注意 `warning-tint` + TriangleAlert，危险 `failed-tint` + OctagonAlert，说明 `data-tint` + Info。圆角 `radius-lg`，图标与标题同色，正文 `text-primary`。不用彩色左边框。
- **代码块**：`surface-2` + `border-default` + `radius-lg`；顶部文件名标签栏（`code-sm`，`text-muted`）+ 右侧"复制"按钮；关键字 `brand-text`，字符串 `cat-data`，属性名 `data`，注释 `text-muted`。
- **Terminal**：安装命令专用，包管理器标签（npm / pnpm / yarn）+ `$` 提示符 + 复制按钮。
- **实时演示框**：`canvas` 底 + 点阵 + `radius-xl`，内嵌真实组件；右上角"在演练场打开"。
- **Props 表**：列为 属性 / 类型 / 默认值 / 说明；属性名代码胶囊，必填加 `status-failed` 星号，新增属性加版本胶囊（如 `1.3.0`）。
- **步骤列表**：编号圆点（`surface-3` 底，当前步 `brand-500`）+ 竖线连接，用于教程。
- **版本标记**：页面标题旁用版本胶囊注明"自 v1.3.0 起"。

## 写作规则

- 每页开头一句话说明"读完能做到什么"。
- 先给能复制运行的最小示例，再解释参数。
- 截图与录屏使用当前版本、深色主题、真实示例数据；每张图配一句说明。
- 链接文字写目的地（"查看 Providers 参考"），不写"点这里"。
